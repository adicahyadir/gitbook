## 📦 1. E-Commerce ASMODARKNESS™ APPAREL

<p align="center">
  <img src="https://emiozfkxrasjzwhkulwb.supabase.co/storage/v1/object/public/uploads/img_5bk00x8_1779341457906.png" alt="E-Commerce ASMODARKNESS APPAREL" width="85%" style="border-radius: 12px; border: 1px solid rgba(255,255,255,0.1);" />
</p>

### Overview
* **Domain:** Modern Streetwear & Apparel E-Commerce.
* **Category:** Web App / Commercial Template.
* **Timeline:** 2026 • **Status:** `Completed`
* **Problem Solved:** Traditional e-commerce templates are often heavy, bloated with unused plugins, and sluggish on mobile devices. ASMODARKNESS™ delivers an editorial, high-fashion dark-mode experience with instant page transitions and frictionless cart checkout.

### Technical Architecture
* **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS.
* **Interactions:** Framer Motion for editorial lookbook transitions and drawer states.
* **Cart & Persistence:** Client-side persisted store with optimistic state updates.
* **Media Optimization:** Next.js Image optimization pipeline served via Supabase CDN storage.
